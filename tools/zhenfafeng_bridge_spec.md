# 阵法峰 · 语法机关桥 — 桥段美术重绘规格

基于 `resources/assets/images/ui/zhenfafeng/background.png`（941×1672）缺口实测，供美术出图对齐。

## 背景缺口锚点（当前场景）

| 项目 | 数值 |
|------|------|
| 缺口垂直中心 | 原图 y ≈ **846px**（**50.6%** 高度） |
| 缺口水平中心 | 原图 x ≈ **50.5%** 宽度 |
| 缺口宽度（雾气带） | 原图宽约 **9.4%** |
| 整段石桥可视宽度 | 原图宽约 **83%**（含两侧桥身） |

前端叠放参数（`PracticeView.vue`）：

- 背景与桥段共用 **`zf-scene-stage`**（`aspect-ratio: 941/1672`），舞台按 **`cover` 逻辑铺满视口**（`width/height: max(...)` + 居中裁切），桥段按原图百分比锚定。
- 桥段锚点（相对舞台）：`left: 50.5%`，`top: 51.45%`，`width: 80%`。
- 透视：`rotateX(24deg)`，`scaleY(0.78)`。
- 移动：`top: 51.8%`，`width: 84%`，`rotateX(20deg)`。

## 现有素材问题

1. `correct_bridge.png` / `error_bridge.png` 为**正面 UI 横条**（1536×1024），与背景**斜透视青石断桥**材质不一致。
2. 装饰卷草 + 强外发光，贴到写实场景上像 HUD，不像桥墩。
3. 黑底 PNG 需依赖 `mix-blend-mode` 融合，边缘仍偏「贴片」。

## 重绘目标

出两张桥段：**补在背景缺口处的一截石桥**，而非通用标题栏。

### 画面内容

- **形态**：1 段横向石桥，左右各 1 块桥墩/桥头，中间为**可嵌入缺口的桥面**。
- **材质**：与背景一致的风化青石、苔藓、裂纹；可带少量**青色符文**（与背景桥身符文同色）。
- **透视**：桥面向镜头下方倾斜约 **14°~18°**（与背景断桥一致），略带纵深感。
- **透明**：PNG 透明底；**不要**大面积纯黑底（减少混合模式依赖）。

### 答对版 `correct_bridge.png`

- 主色：暖金灵光沿符文与裂缝渗出（**不要整图金黄 UI 化**）。
- 可加轻微粒子 / 光晕，但**不超过桥面范围**。
- 情绪：机关接通、可通行。

### 答错版 `error_bridge.png`

- 主色：暗红/赤铜裂纹光，饱和度**低于**当前素材约 20%。
- 可加轻微火星/碎屑，表现机关报错、桥未稳固。
- 情绪：断裂、拒行；**避免**整块霓虹红横条。

### 尺寸建议

| 项目 | 建议 |
|------|------|
| 画布 | 1600×900 或 1800×1000（横向） |
| 桥段总宽 | 约占画布 **78%~85%**（对齐背景石桥跨度） |
| 中间「补洞」区 | 约占画布宽 **12%~18%** |
| 安全边距 | 上下各留 8%，便于 CSS `object-fit: contain` |

### 对齐参考

出图时可将 `background.png` 置于下层 50% 透明度，桥段叠在 **y=846** 附近缺口处验收；左右桥身纹理方向、厚度、透视须连贯。

## 前端验收标准

1. 桥段中心落在背景缺口，左右与桥身无明显错位（1080p / 1440p / 手机竖屏）。
2. 答对/答错一眼可辨，但不压过题干卷轴与底部选项。
3. 不依赖强 `mix-blend-mode` 也能自然融入场景。
